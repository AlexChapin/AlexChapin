## 🚀 Featured Computer Science Projects

### 🤖 FRC Robotics Software & ML Vision
*   **The Mission:** Built intelligent autonomous systems for field navigation and target acquisition.
*   **The Tech:** Developed custom machine learning vision models for object detection and field localization.
*   **The Code:** Authored robust data processing libraries in **Java** and engineered dynamic pathfinding algorithms.
*   **The Win:** Secured the *FIRST Chesapeake District Autonomous Award*.

*   **The Code:** Architected and coded the entire large-scale prototype system in **Python**.
